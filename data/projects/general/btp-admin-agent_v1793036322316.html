Executive Summary

This document outlines the steps to retrieve the list of currently activated services within a specific SAP BTP sub‑account. It covers the use of the BTP CLI, the Accounts Service REST API, and provides example JSON outputs. The objective is to enable administrators to audit service usage, verify entitlements, and support downstream automation.

Step‑by‑Step Instructions

1. Install & Configure the BTP CLI

curl -sL https://nodejs.org/dist/v20.11.1/node-v20.11.1-linux-x64.tar.gz | tar xz
cd node-v20.11.1-linux-x64
export PATH=$PWD/bin:$PATH
npm i -g @sap/btp-cli
btp login --user <your_username> --password <your_password> --url https://account.eu10.hana.ondemand.com

2. Set the Sub‑account Target

btp target subaccount --id S7890ABCD
btp target environment --region eu10 --type production

3. Retrieve Service List via CLI

btp account services list --output json

This command returns a JSON array of service instances with details such as serviceId, serviceName, plan, region, and status.

4. Retrieve Service List via REST API

Authenticate using OAuth2 to obtain an access token.

curl -k -X POST https://account.eu10.hana.ondemand.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=password" \
  -d "client_id=<client_id>" \
  -d "client_secret=<client_secret>" \
  -d "username=<your_username>" \
  -d "password=<your_password>"

Response snippet:

{
  "access_token":"eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type":"bearer",

Use the token to query the Accounts Service API.

curl -H "Authorization: Bearer <access_token>" \
  https://api.eu10.hana.ondemand.com/api/subaccount/S7890ABCD/serviceInstances?size=1000

Troubleshooting

API Token Acquisition Fails

  • Check that client_id and client_secret are correct.
  • Ensure the user account has the subaccount.viewer role.
  • Verify that the account endpoint matches the region (eu10).

Service List Empty but Services Present

  • Confirm the subaccountId used in the API URL matches the target sub‑account.
  • Check if the user has serviceInstance.viewer privileges.
  • Verify that the API endpoint is https://api.eu10.hana.ondemand.com/api/subaccount/S7890ABCD/serviceInstances and not the Cloud Foundry API.

CLI Command Returns Error “Unable to reach server”

  • Confirm network connectivity to account.eu10.hana.ondemand.com and api.eu10.hana.ondemand.com.
  • Ensure the latest BTP CLI is installed (npm i -g @sap/btp-cli).
  • Re‑authenticate with btp login.

Responsible AI & Security Considerations

All credentials (passwords, client secrets, JWTs) are transient and never stored in plain text. Use environment variables or secure vaults (e.g., SAP Credential Store) for production automation.

Do not embed sensitive data in the HTML or commit it to source control. Keep this document for internal use only.

Ensure that all API calls are performed over HTTPS and that certificates are validated. If you encounter self‑signed certificates (e.g., in sandbox environments), configure the CLI or your HTTP client to trust the certificate authority securely.
