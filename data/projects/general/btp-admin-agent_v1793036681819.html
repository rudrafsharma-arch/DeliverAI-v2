Step‑by‑Step Instructions

1. Target the Subaccount in the BTP CLI

btp target --subaccount {SUBACCOUNT_ID} --region {REGION}

2. List All Cloud Foundry Service Instances

btp services --format json

The output will be a JSON array with details for every service instance in Cloud Foundry. To filter by category, use the --filter flag.

3. List All Kyma Services

btp services --filter category:kyma --format json

4. List Integration Suite Instances (iPaaS)

btp services --filter category:integration --format json

5. Use the REST API (for audit scripts)

Authenticate with an OAuth2 client that has the uaa.clients scope.

curl -k -X POST https://{SUBACCOUNT_ID}.btp.sap:443/oauth/token \
     -d "grant_type=client_credentials" \
     -d "client_id={CLIENT_ID}" \
     -d "client_secret={CLIENT_SECRET}" \
     -d "audience=b2c.btp.sap" \
     -H "Content-Type: application/x-www-form-urlencoded"

Response contains an access_token. Use it to call the service manager API:

curl -k -X GET https://{SUBACCOUNT_ID}.btp.sap/api/v1/service-instances \
     -H "Authorization: Bearer <access_token>" \
     -H "Accept: application/json" | jq '.serviceInstances'

6. Export to CSV

Use jq to transform the JSON into CSV:

curl ... | jq -r '.serviceInstances[] | [.name, .serviceName, .plan, .createdAt, .lastUpdated, .url] | @csv' > services.csv

7. Verify Service Health

  • Check the BTP Cockpit Health Dashboard.
  • Run cf services inside the relevant Cloud Foundry space.
  • Use kubectl get services -n kyma-system for Kyma.

Verification Steps

  1. Run btp services --format json and verify that the number of rows matches the inventory table.
  2. Access each service URL via HTTPS and confirm a 200 OK response.
  3. Check the service instance status in BTP Cockpit; it should be Active.
  4. For Cloud Foundry services, use cf service <instance-name> to view plan and binding details.
  5. Perform a test binding (e.g., cf create-service-key) to ensure the service key can be generated.

Troubleshooting

Common Issue 1: API call returns 401 Unauthorized

  • Verify that the client_id and client_secret are correct.
  • Check that the OAuth2 client has the uaa.clients scope.
  • Ensure the token endpoint URL matches the region (e.g., https://{SUBACCOUNT_ID}.btp.sap).

Common Issue 2: Service instance shows Pending state for >5 minutes

  • Confirm that the quota for the service plan is not exceeded.
  • Review the service logs via BTP Cockpit or cf logs <app>.
  • If persistent, raise a support ticket with SAP.

Common Issue 3: BTP CLI returns "Target not found"

  • Verify that the subaccount ID and region are spelled correctly.
  • Check that your user has the Subaccount Administrator role.
  • Run btp login again to refresh the session.
