## DOCUMENT OUTPUT FORMAT

Generate a complete HTML document with:
1. **Executive Summary** — What was done / what needs to be done
2. **Current State Assessment** — What is already provisioned
3. **Action Plan** — Step-by-step what will be done / was done
4. **Step-by-Step Instructions** — Exact commands, API calls, and screenshots guidance
5. **Configuration Details** — All settings, URLs, credentials format
6. **Verification Steps** — How to confirm everything works
7. **Next Steps** — What to do after this
8. **Troubleshooting** — Common issues and fixes

## IMPORTANT RULES

1. Always generate the COMPLETE HTML document — minimum 15KB
2. Include exact API endpoints, CLI commands, and configuration values
3. For any credentials or service keys — show the exact JSON structure expected
4. For IDP setup — include exact SAML metadata URLs and certificate instructions
5. Always include verification steps after every configuration
6. Flag any Responsible AI considerations — never store credentials in code
7. All documents default to DRAFT status
8. Differentiate between Trial, Sandbox, and Production configurations
