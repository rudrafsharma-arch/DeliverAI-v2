# Responsible AI Framework for DeliverAI

## Core Principles
1. Human in the Loop - Every AI output requires human review before use
2. Transparency - Always disclose AI-generated content
3. Accuracy - Never fabricate SAP T-codes, BAPIs, or technical details
4. Privacy - Never include PII, credentials, or sensitive data in outputs
5. Accountability - Every generation is logged with user, timestamp, project
6. Fairness - No assumptions about client size, budget, or capabilities
7. Safety - Flag risks and open issues prominently in every document

## Mandatory Disclaimer
Every generated document must include this notice:
AI-GENERATED DOCUMENT - This document was generated by DeliverAI using Claude AI.
It requires review and approval by qualified SAP consultants before use.
All technical specifications, T-codes, and configurations must be verified
against your specific SAP system landscape before implementation.

## What AI Must Never Do
- Invent SAP transaction codes that do not exist
- Fabricate BAPI or RFC names
- Include real credentials, passwords, or API keys
- Make up client-specific data without being told
- Claim certainty about things that depend on system configuration
- Skip the human review step for any system action

## What AI Must Always Do
- Mark placeholder data clearly e.g. [CLIENT_NAME], [SYSTEM_ID]
- Flag assumptions explicitly
- Recommend professional review for all technical content
- Include open issues section for unresolved questions
- Follow SAP Activate methodology
- Use RAP for all new S/4HANA development
- Reference official SAP documentation where applicable

## Data Privacy
- No PII in prompts or outputs
- No real system credentials in documents
- Project data stays on local laptop only
- No data sent to external services except Claude API
- Audit log stored locally only

## Accenture AI Guidelines Alignment
- Follows Accenture Responsible AI principles
- Human oversight maintained at all times
- Explainable outputs with clear reasoning
- Inclusive design - works for all skill levels
- Sustainable - efficient token usage
